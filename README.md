# Le Rameau d'Olivier — maquettes de refonte

Cinq propositions graphiques navigables pour la refonte du site rameau-olivier.fr.

Les pages statiques sont générées par `outils/generer.py`, à partir du contenu du site actuel (`outils/contenu.json`).

- Régénérer : `python3 outils/generer.py`
- Vérifier les liens : `python3 outils/verifier.py`
- Consulter en local : `./lancer.sh`, puis ouvrir http://localhost:8080/index.html
- En ligne : https://nicownchtr.github.io/rameau-olivier-maquettes/

Les consignes de travail pour Claude sont dans `CLAUDE.md`.
